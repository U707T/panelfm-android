## 5. 踩过的坑（务必避免重犯）

### 5.1 加密 ZIP（`ZipCrypto`）——三个真 bug，已修且有回归测试
1. **密钥流是 per-entry 的**，不是全流连续（曾误以为像 RAR 那样跨条目推进 → 第二个条目起全解不开）
2. **必须用裸 deflate**（`Deflater(level, /* nowrap = */ true)`），带 zlib 头会解出 `78 9c` 导致 inflate 失败
3. **`reader` 回调必须写入调用方提供的缓冲区**（早期签名 `() -> Int` 让调用方写自己的缓冲区 → 写侧永远压到全零）
4. 加解密**不是同一个运算**：两者都用「明文」推进密钥，所以 `encrypt`/`decrypt` 分开实现

> 回归测试：`ZipCryptoTest`（与 Python 参考实现逐字节对照）+ `EncryptedZipRoundTripTest`（用 Python zipfile 交叉验证）

### 5.2 沙箱 / 构建
- Gradle 一律加 `--offline`（网络受限）
- `commons-compress 1.27` **只有加密 ZIP 读侧**，写侧必须自研
- SMBJ 没有 `File.setFileTime`，要用 `setFileInformation(FileBasicInformation(...))`
- SSHD 的 `SftpClient.Attributes` 用 `modifyTime(FileTime)`，不是 `mtime =`
- Kotlin 字符串模板后面紧跟中文要加花括号：`"${verb}并替换"`

### 5.3 手写补丁的注意点
- 用脚本批量改 Kotlin 时，**务必改完立刻编译**：出现过两次「两行被拼成一行」的静默错误
- 改 `when` 分支 / `data class` 参数时，先 `grep` 所有调用点
- **`data class` 里加 `val singlePane` 这种派生属性时，不能用 `copy(singlePane = …)`** ——
  派生属性要写成 `val x: Boolean get() = …`，否则编译期报「No parameter with name」
