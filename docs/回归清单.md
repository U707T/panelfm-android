# PanelFM 真机回归清单（每次发版前过一遍）

## 1. 权限与首启
- [ ] 首启主页出现「所有文件访问」引导卡 → 点「去授权」→ 授权后回到 App，卡片消失。
- [ ] Android 17 真机：出现「局域网访问」引导卡；未授权时连接 NAS 报错文案为「系统未允许访问局域网」，**不是**含糊的超时。
- [ ] 拒绝权限时浏览 `/storage/emulated/0` 给出「可能需要『所有文件访问』授权」的明确提示。

## 2. 本地双列
- [ ] 左右窗格可分别导航到不同目录；各自 `← / →` 历史独立且能还原。
- [ ] 长按进入多选；`全选`；`已选 N 项` 显示正确。
- [ ] 排序（名称/大小/时间/类型、升降序、文件夹置顶）刷新后生效。
- [ ] 隐藏文件开关即时生效。
- [ ] 列表副标题显示 `文件夹: N  文件: M  已用/总量`。

## 3. 跨窗格操作（核心）
- [ ] 选中项 → `⇄ → 复制到对面`：两侧路径栏同时高亮 ~1.6s，底部提示文案含目标路径。
- [ ] 任务条出现进度/速率/剩余时间；可暂停、继续、取消。
- [ ] 同名文件触发冲突弹窗：覆盖 / 跳过 / 保留两者 / 全部应用，四种结果都正确落盘。
- [ ] `移动到对面` 弹二次确认（项数/体积/是否跨存储）；确认后源文件消失、目标出现。
- [ ] `同步路径到对面`：同协议跳到同路径；压缩包内部（后续 M8）跳到压缩包所在目录。
- [ ] `交换窗格` 后左右内容互换，焦点跟随。
- [ ] 空目录点 `⇄` 给出「当前目录没有可操作的项」而不是静默失败。

## 4. 网络协议
- [ ] 添加 WebDAV（自建 Alist `http://192.168.28.156:5244/dav`）：列表、下载、上传、重命名、服务端复制/移动、删除均可用。
- [ ] 添加 FTP：MLSD 列表、下载断点续传（传一半取消后再传，从断点继续）。
- [ ] FTPS 显式（AUTH TLS）与隐式（990）各连一次；自签证书勾选「信任自签」后能连。
- [ ] 跨协议（WebDAV → 本地、本地 → FTP）复制有进度且结果正确。
- [ ] 连接错误（端口写错/密码错/未授权局域网）给出可执行文案，不是崩溃或空白。

## 5. 预览
- [ ] `.txt`（UTF-8）与 `.txt`（GBK）都能正确显示中文（顶部显示识别到的编码）。
- [ ] 大文件（> 1 MB 文本）显示「已截断」提示且不死。
- [ ] 图片（jpg/png/webp）能显示；损坏图片给出「可点 Hex 查看」的提示。
- [ ] 二进制文件（.so/.dex）默认走 Hex，偏移与 ASCII 列对齐正确。
- [ ] 本地文件点「外部应用」能拉起系统应用（FileProvider 授权正常）。

## 6. 稳定性
- [ ] 传输中切到后台再回来，任务仍在继续/可继续。
- [ ] 传输中杀进程重开：未完成任务不再运行，不残留 `.panelfm.part`（本地）或临时文件。
- [ ] 旋转屏幕/切换深色模式，浏览位置与选择集不丢。
- [ ] 连续操作 30 分钟后内存无异常增长（Android Studio Profiler）。
