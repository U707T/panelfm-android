## 0. 本轮新增回归（v1.0.0 · 解析文档 P1/P2 收尾）

### 对比器（`0x7f0e000a`）
- [ ] 打开两个文本文件 → 顶栏有「↑ 上个差异 / ↓ 下个差异」，点按在差异块间跳转（含首尾循环）。
- [ ] ⋮ → 「忽略」四档：不忽略 / 忽略首尾空格 / 忽略全部空格 / 忽略空格和空行；
      切档后差异数实时变化；「忽略空格和空行」时空行消失但行号仍指原文。
- [ ] ⋮ → 「Aa」勾选/取消「区分大小写」：`Abc` vs `abc` 从差异变相同（反之亦然）。
- [ ] ⋮ → 「◫」浏览模式：自动切换（平板/横屏双列，手机单列）/ 双列（左右并排）/ 单列（带 +/- 前缀）。
- [ ] 两文件完全一致时显示「未找到任何差异」。
- [ ] 超过 20000 行时提示「⚠ 文件较大，已截断到 20000 行后对比」。

### 编辑器（`0x7f0e001b` / `0x7f0e000e`）
- [ ] ⋮ → 行操作：复制行 / 剪切行 / 删除行 / 清空行 / 重复行 —— 光标所在行正确变化。
- [ ] ⋮ → 转为大写 / 转为小写 / 增加缩进 / 减小缩进 —— 全文生效，空行不加缩进。
- [ ] ⋮ → 切换注释：`.kt`/`.java`/`.js`/`.css` 用 `//`，`.py`/`.sh`/`.yml`/`.properties` 用 `#`；
      `.txt`（纯文本）提示「当前语言不支持切换注释」；重复点按能还原（不累积空格）。
- [ ] ⋮ → 压缩代码（去空白）：行尾空白被去掉、首尾空行被去掉、中间空行保留。
- [ ] ⋮ → 格式化代码：`.json` 紧凑文本变成缩进格式（字符串里的 `{}[],:` 不被破坏）；
      `.xml` 按标签深度缩进（属性里的 `>` 不截断标签）；其它语言提示「暂不支持」。
- [ ] ⋮ → 转到指定行：输入行号 → 光标跳到该行；非法输入提示。
- [ ] 查找条：输入框 + 🕘历史 + 上个 + 下个 + 替换 + 全部替换；勾选「正则表达式 / 区分大小写 / 全词匹配」
      后行为正确；找不到时提示带开关组合（如「找不到文本（已开启正则表达式和区分大小写）」）。
- [ ] 查找/替换过的词进入历史（下次点 🕘 能选到）。

- [ ] 批量重命名：表达式 / 查找内容 / 替换内容 三处都有 🕘 历史。

### Hex 数值解释（`0x7f0c002a`）
- [ ] 二进制文件（.so/.bin）走 Hex 只读视图 → 点「数值解释」展开面板。
- [ ] 点列表任意行：面板偏移跟着变（该行高亮）。
- [ ] ☑ 大端模式 切换后，短整/整数/长整/浮点的取值按端序变化。
- [ ] 解释项齐全：字节 / 字节(无符号) / 短整数 / 短整数(无符号) / 整数 / 整数(无符号) /
      长整数 / 单精度浮点数 / 双精度浮点数 / UTF8 字符串 / Unicode 字符串。

### 「再按一次」范式（`0x7f11055c`）
- [ ] 在文件系统根目录（如「内部存储」根）按返回：提示「再按一次返回上级」（不是直接退出）。
- [ ] 2 秒内再按返回：回到上级 / 首页。
- [ ] 子目录按返回：**直接**返回上级（不提示）。
- [ ] 开启「退出前双次确认」后：主页连按两次返回才退出。

### 「选择当前目录」模式（`0x7f0c0025`）
- [ ] 压缩包内 → ⋮ →「解压…」→ 选「解压到文件夹…」→ 底栏上方出现
      「选择当前目录：<路径> / 解压到所选目录 / 取消」。
- [ ] 浏览到目标目录 → 点「解压到所选目录」→ 解压到该目录。
- [ ] 点「取消」退出该模式，底栏恢复原样。
- [ ] 选中项 → 顶栏动作条「📂 复制到…（选择目录）」→ 同流程 → 点「复制到所选目录」执行复制。
- [ ] 该模式下按返回：退出该模式（不返回上级）。

### 浏览模式 / 对话框图标
- [ ] ⋮ →「浏览模式（…）」→ 三档：自动切换 / 单列 / 双列；选完立即生效；
      手机竖屏选「自动切换」= 单列，横屏/平板 = 双列。
- [ ] 设置 → 界面 → 浏览模式三档同样生效；「默认单列显示」开关切换后运行期立即生效（无需重启）。
- [ ] 设置 → 界面 →「对话框图标背景」三档：打开「属性」与「冲突」对话框，
      图标底色在「深色 / 浅色 / 无背景」间变化（深色主题下自适应反相）。
