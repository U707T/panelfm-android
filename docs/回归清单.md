# PanelFM 真机回归清单（每次发版前过一遍）

## 1. 权限与首启
- [ ] 首启主页出现「所有文件访问」引导卡 → 点「去授权」→ 授权后回到 App，卡片消失。
- [ ] Android 17 真机：出现「局域网访问」引导卡；未授权时连接 NAS 报错文案为「系统未允许访问局域网」，**不是**含糊的超时。
- [ ] 拒绝权限时浏览 `/storage/emulated/0` 给出「可能需要『所有文件访问』授权」的明确提示。

## 2. 本地双列
- [ ] 左右窗格可分别导航到不同目录；各自 `← / →` 历史独立且能还原。
- [ ] **向右滑动任意项 ≥ 24dp = 进入多选**（轻微震动）：滑动单项 = 只选中该项；继续滑过行间 = 连续区间选择（替换语义）。
- [ ] 小幅度横向拖动后松手：**不打开文件**（防误触）；原位轻点仍能正常打开。
- [ ] 任何触摸（含滚动、点空白）都会切换活动窗口：同一时间只有一个窗格高亮为活动态，另一侧明显变淡。
- [ ] 多选态下纵向拖动列表仍能滚动；单击已选项 = 取消选中。
- [ ] 长按文件并移动手指：不出现拖拽幽灵 / 不触发复制（仅松手后弹动作菜单）。
- [ ] **长按后松手 = MT 动作菜单**（该项自动选中；批量选中的文件夹可复制 / 移动 / 删除 / 压缩 / 批量重命名）（有震动反馈）；长按后拖动不再触发任何跨窗格动作（长按拖动已按需求移除，跨窗格走动作菜单「复制 -> / 移动 ->」或 `⇄`）。
- [ ] 动作菜单箭头跟随目标窗口：选中项在左窗格显示 `复制 ->` / `移动 ->`；在右窗格显示 `<- 复制` / `<- 移动`。
- [ ] `全选 / 反选 / 类选 / 同步 / 取消` 可用；`已选 N 项` 显示正确。
- [ ] 排序（名称/大小/时间/类型、升降序、文件夹置顶）刷新后生效。
- [ ] 隐藏文件开关即时生效。
- [ ] 列表副标题显示 `文件夹: N  文件: M  已用/总量`。

## 3. 跨窗格操作（核心）
- [ ] 选中项 → `⇄ → 复制到对面`：两侧路径栏同时高亮 ~1.6s，底部提示文案含目标路径。
- [ ] 任务条出现进度/速率/剩余时间；可暂停、继续、取消。
- [ ] 同名文件触发冲突弹窗：覆盖 / 跳过 / 保留两者 / 全部应用，四种结果都正确落盘。
- [ ] `移动到对面` 弹二次确认（项数/体积/是否跨存储）；确认后源文件消失、目标出现。
- [ ] `同步路径到对面`：同协议跳到同路径；压缩包内部（后续 M8）跳到压缩包所在目录。
- [ ] `交换窗格` 后左右内容互换，焦点跟随。
- [ ] 空目录点 `⇄` 给出「当前目录没有可操作的项」而不是静默失败。

## 4. 网络协议
- [ ] 添加 WebDAV（自建 Alist `http://192.168.28.156:5244/dav`）：列表、下载、上传、重命名、服务端复制/移动、删除均可用。
- [ ] **Alist `basePath=/dav` 回归（v0.13.0-rc.3 修复点）**：编辑连接 → URL 填 `http://host:5244/dav` → 测试连接显示「根目录 N 项」；
      打开后请求应为 `/dav`，**不再**出现「文件不存在：dav」（旧版会请求 `/dav/dav` 导致 404）。
- [ ] 编辑连接（复刻 MT）：URL 单行输入自动解析端口/路径；👁 可查看密码；「初始路径」填写子目录后打开直达；
      「在侧拉栏隐藏地址」开关生效（≡ 抽屉不再显示、主页仍可见并可长按编辑）；「缩略图选项 → 加载缩略图」关闭后该连接列表不加载缩略图。
- [ ] 反向代理给集合补 `/`（301 重定向）的 WebDAV：PROPFIND 等请求能正常跟随（不断言降级为 GET 导致的失败）。
- [ ] 添加 FTP：MLSD 列表、下载断点续传（传一半取消后再传，从断点继续）。
- [ ] FTPS 显式（AUTH TLS）与隐式（990）各连一次；自签证书勾选「信任自签」后能连。
- [ ] 跨协议（WebDAV → 本地、本地 → FTP）复制有进度且结果正确。
- [ ] 连接错误（端口写错/密码错/未授权局域网）给出可执行文案，不是崩溃或空白。

## 5. 预览
- [ ] `.txt`（UTF-8）与 `.txt`（GBK）都能正确显示中文（顶部显示识别到的编码）。
- [ ] 大文件（> 1 MB 文本）显示「已截断」提示且不死。
- [ ] 图片（jpg/png/webp）能显示；损坏图片给出「可点 Hex 查看」的提示。
- [ ] 大图 / 远程图片（含 30MB+）可打开（流式解码，不 OOM）；双击切换 1x/2.5x，捏合缩放，双指平移。
- [ ] 多选态下右滑其它行 = 加选该行；从锚点滑过行间 = 区间选择（替换语义）。
- [ ] Wi-Fi 下网络图片缩略图正常加载；切到移动数据且设置关闭时不加载（不再强制下载）。
- [ ] 二进制文件（.so/.bin）默认走只读 Hex，偏移与 ASCII 列对齐正确（不做 Hex 编辑）。
- [ ] 本地文件点「外部应用」能拉起系统应用（FileProvider 授权正常）。

- [ ] 界面：主页三段可折叠；本地项显示占用百分比；双列 ⋮ 菜单项与 MT 一致（刷新/输入路径/搜索/全选/过滤/排序/隐藏文件/添加书签/设为首页/交换窗口/设置/退出）。
- [ ] 「设为首页」后重启 App，左窗格进入该目录。
